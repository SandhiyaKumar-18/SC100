# 🛡️ SC-100: Microsoft Cybersecurity Architect Expert – Roadmap

## 🎯 Objective
This roadmap guides you through mastering all exam domains of SC-100, Microsoft's expert-level certification for cybersecurity architects. It includes learning paths, skills, and checklists to help you design Zero Trust, GRC, infrastructure, and data/application security strategies across Microsoft cloud solutions.

---

## 📘 Exam Overview

- **Exam Code:** SC-100
- **Level:** Expert
- **Role:** Microsoft Cybersecurity Architect
- **Skills Measured:**
  - Design a Zero Trust strategy and architecture (25–30%)
  - Evaluate GRC (Governance, Risk, and Compliance) technical strategies (20–25%)
  - Design security for infrastructure (20–25%)
  - Design a strategy for data and applications (20–25%)
- **Official Link:** [Microsoft Learn - SC-100](https://learn.microsoft.com/en-us/certifications/exams/sc-100/)

---

## 🧩 Domain 1: Design a Zero Trust Strategy and Architecture (25–30%)

### 🔹 Key Topics
- Zero Trust principles and architecture pillars
- Identity and access design (RBAC, PIM, Conditional Access)
- Network access control strategy
- Device & endpoint protection
- Application access design
- Security operations strategy (SIEM, SOAR, Sentinel)
